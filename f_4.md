## Set

Set is a collection of objects, called elements. The elements of a set are usually denoted by lowercase letters, and the set itself is denoted by a capital letter. For example, the set of all integers is denoted by $\mathbb{Z}$, and the set of all real numbers is denoted by $\mathbb{R}$.

We use braces to perform sets, such as Set A = $ \{1,2,3,4,5\}$. We can also use the notation $A = \{x | x \in \mathbb{Z}, x \geq 0\}$ to perform the set of all non-negative integers.

## Symbols of Set Theory

- $\in$ means "is an element of"
- $\notin$ means "is not an element of"
- $\subset$ means "is a subset of"
- $\supset$ means "is a superset of"
- $\subseteq$ means "is a subset of or equal to"
- $\emptyset$ means "the empty set"
- $\cup$ means "union"
- $\cap$ means "intersection"
- $\setminus$ means "difference"
- $\times$ means "cartesian product"
- $\bigcup$ means "union of a family of sets"
- $\bigcap$ means "intersection of a family of sets"
- $\forall$ means "for all"
- $\iff$ means while left is equal to right, right is equal to left.
- $\land$ means and, which means it need left and right passenger to be true.
- $\lor$ means or, which means it need left or right passenger to be true.
- $\neg$ means not, which means it need left passenger to be false.
- $\exists$ means exists, which means it need left passenger to be true.
- $\mathbb{N}$ means the set of all natural numbers (often $\{0,1,2,3,\dots\}$ or $\{1,2,3,\dots\}$)
- $\mathbb{Z}$ means the set of all integers
- $\mathbb{Q}$ means the set of all rational numbers (numbers that can be written as $\frac{p}{q}$ with $p,q\in\mathbb{Z}, q\neq 0$)
- $\mathbb{R}$ means the set of all real numbers
- $\mathbb{C}$ means the set of all complex numbers (numbers of the form $a+bi$ with $a,b\in\mathbb{R}$ and $i^2=-1$)
- $\mathbb{P}$ means the set of all prime numbers
- $\mathbb{H}$ means the set of all quaternions

## Defination

1. $\in$ means in. If an element or a set A is equal to another set B, then it is in, perform as $A\in B$.
2. $\notin$ means not in. If an element or a set A is not equal to another set B, then it is not in, perform as $A\notin B$.
3. $\subset$ means a set A is almost same as set B, which means their element is same, but loss some element, we perform as $A\subset B$.
4. $\supset$ is the oppsite of subset, pronounce as superset. If $A \subset B$, then $B \supset A$.
5. $\subseteq$ means a set A is a subset of another set B, but it is equal to set B, perform as $A\subseteq B$.
6. $\emptyset$ means the empty set, which means it has no element, perform as $\emptyset$ or $ \{\} $.
7. $\cup$ means union, which means put all of the element of set A and set B, perform as $A\cup B$.
8. $\cap$ means intersection, which means put the same element in set A and set B, perform as $A\cap B = \{x|x\in A, x\in B\}$.
9. $\setminus$ is means some element there is not in a set but in other set. For example, if A $\setminus$ B, it will equal to element inside set A but not in set B. Perform as $A\setminus B = \{x\in A, x\notin B\}$.
10. $\times$ is not only a multiply simbol. It also means Cartesian product. For example, if A $\times$ B, it will equal to all of the element in set A and set B. Perform as $A\times B = \{(x,y)|x\in A, y\in B\}$. But it is useless at all.
11. $\bigcap$ means intersection of a set of sets, perform as $\bigcap_{i=1}^{n} A_i = \{x|x\in A_i, \forall i\in \{1,2,...,n\}\}$.
12. $\bigcup$ means union of a set of sets, perform as $\bigcup_{i=1}^{n} A_i = \{x|x\in A_i, \exists i\in \{1,2,...,n\}\}$.
13. $\forall$ is means all. For example, if $ \forall x $ in A, it means all of the element named x in set A.
14. $\exists$ is means exists. For example, if $\exists x\in A, it means there is a element named x in set A.
15. $\land$ is means and. For example, if $P\land Q$, it means P and Q are both true.
16. $\lor$ is means or. For example, if $P\lor Q$, it means P or Q are both true.
17. $\neg$ is means not. For example, if $\neg P$, it means P is false.
